# AI-Based-Exam-Cheating-Detection-System

AI-powered online exam monitoring system using MediaPipe, OpenCV, and Python.  
The project detects suspicious activities using real-time face tracking, eye gaze detection, head movement analysis, and posture monitoring.

## Features
- Real-time webcam monitoring
- Eye gaze detection
- Head movement tracking
- Posture analysis
- Suspicious activity alerts
- Automatic snapshot capture

## Technologies Used
- Python
- MediaPipe
- OpenCV
- HTML/CSS/JavaScript
- Google Colab

## How to Run
1. Open the notebook in Google Colab or Jupyter Notebook
2. Install required libraries
3. Run all cells
[Open in Colab](https://colab.research.google.com/)
